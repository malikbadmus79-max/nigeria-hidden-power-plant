# Where Solar Beats the Generator: Nigeria, State by State, Month by Month (2023–2026)

Monthly estimates of what households and small businesses pay to run generators in each of Nigeria's 36 states and the FCT, compared with grid tariffs and solar-plus-battery costs, showing when and where solar became the cheaper option.

**Status: Phase 4 audit completed 2026-11-27 (`docs/phase4_audit.md`). All figures are estimates with low–high ranges; see the audit for sources and limits.**
